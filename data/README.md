# Data

German Credit is not committed to this repo. It is loaded by `credit_core.datasets.load_german()`
from `~/.local/share/credit-data/german1/german_credit_data.csv`
(source: `kabure/german-credit-data-with-risk`, Kaggle, public). Download it with the Kaggle CLI
and place it at that path before running the notebook. Retrieval date: see the CR01 repo.
